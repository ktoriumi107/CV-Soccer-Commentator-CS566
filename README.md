Computer Vision Soccer Commentator - CS566 Project
By Varun Sivakumar, Damien Kim, Keiji Toriumi

This project takes a video of a soccer match as input and outputs text that can be used for a commentary. The motivation and implementation details can be found on [this](https://dkamien66.github.io/) webpage.

The code can be downloaded as a zip file and run by calling main.py. The desired video path can be specified on line 15 of main.py as the variable VIDEO_PATH. This allows for the program to be run on any video or the webcam. The requirements can be found in the requirements.txt file.
